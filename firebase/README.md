# Focus Mode+ — Firebase (v21)

Firestore Security Rules, indexes, Emulator Suite configuration, Rules tests and the trusted
account-deletion function for the optional Android account feature. Nothing here is deployed by
the repository, and nothing here is part of the PWA (which stays a no-build static app) or of the
Android APK.

| File | Purpose |
|---|---|
| `firestore.rules` | Deny-by-default Rules: owner-only `/users/{uid}/...`, exact fields, bounds, versions, reserved-field protection |
| `firestore.indexes.json` | No composite index is needed (single-field `serverUpdatedAt` queries) |
| `firebase.json`, `.firebaserc` | Emulator Suite (Auth 9099, Firestore 8080) for the demo project `demo-focus-mode` |
| `test/firestore.rules.test.cjs` | Rules tests with `@firebase/rules-unit-testing` |
| `test/account-deletion.test.cjs` | Recursive deletion tests with the Admin SDK against the emulator |
| `test/fixtures/client-payloads.json` | Documents exactly as the Android codec writes them (generated by `RemoteCodecTest`) |
| `functions/` | `deleteUserDataOnAccountDeletion` (Auth `onDelete` → recursive delete of `/users/{uid}`) |

## Run the tests

Requirements: Node ≥ 24.12, Java 21 (for the Firestore emulator).

```bash
cd firebase
npm ci
npm run test:emulator   # firebase-tools 15.37.0 via npx; demo project only, no credentials
```

The demo project id (`demo-…`) keeps the emulators offline from any real project. The tests
refuse to run without `FIRESTORE_EMULATOR_HOST`.

If the Android codec changes, regenerate the fixture and update the Rules together:

```bash
cd android && UPDATE_PAYLOAD_FIXTURES=true ./gradlew :core:domain:test --tests '*RemoteCodecTest*'
```

## Deploy (owner only, after the steps in android/docs/firebase-setup-v21.md)

```bash
npx firebase-tools@15.37.0 deploy --only firestore:rules,firestore:indexes --project <your-project-id>
npx firebase-tools@15.37.0 deploy --only functions:focus-mode --project <your-project-id>   # see android/docs/account-deletion-v21.md
```

Never deploy permissive development Rules (rules that let anyone read or write everything), and never commit a service-account key.
