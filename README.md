# Focus Mode+ PWA

Готовая устанавливаемая PWA-версия Focus Mode+ на основе приложенного HTML.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий, например `focus-mode-plus-pwa`.
2. Загрузи **содержимое этой папки** в корень репозитория.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`, затем `Save`.
6. Подожди публикацию и открой выданный HTTPS-адрес именно в Safari на iPhone.

## Установка на iPhone

1. Открой опубликованный адрес в Safari.
2. Нажми кнопку «Поделиться».
3. Выбери «На экран Домой».
4. Нажми «Добавить».

## Что работает

- отдельная иконка и полноэкранный запуск;
- интерфейс приложения без лендинга и рамки iPhone;
- текущие демо-сценарии Focus Mission и Quick Focus;
- базовый offline-кэш после первого успешного открытия;
- сохранение языка и некоторых настроек через localStorage.

## Ограничения этой версии

- реальная блокировка приложений через Screen Time отсутствует;
- AI и Premium остаются демонстрационными;
- Tailwind, Lucide и Google Fonts сейчас загружаются из CDN при первом открытии, после чего service worker пытается сохранить их в runtime-cache;
- уведомления iOS пока не добавлены;
- активный таймер ещё не восстанавливается надёжно после принудительного закрытия PWA.

## Обновление версии

После изменения файлов поменяй в `service-worker.js`:

```js
const CACHE_NAME='focus-mode-plus-pwa-v2';
```

Иначе iPhone может некоторое время показывать старый кэш.
